# Comment catalog — hoalu

Reference for the `no-comments` skill. Every example is from this repo.

## The test

Before keeping a line, answer one question: **is this fact discoverable from the code in front of me?**

- Yes → delete it.
- No, but it should be → delete it and reshape the code (`MUST FIX`).
- No, and it is caused by something we do not control → keep it, and name that thing.

A comment that survives must be cheap to verify. If you cannot check the claim in under a minute, it is not a comment, it is a rumor.

## Shapes and their fixes

| Shape               | Looks like                                                                                                       | Fix                                                                   |
| ------------------- | ---------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| Next-line narration | `// Walk up to the nearest interactive element` above `target.closest(...)`                                      | Delete. The call already says it.                                     |
| Section banner      | `// Category mode data: build per-category series then merge into grouped records`                               | Extract a named function that says the same in its name.              |
| Step markers        | `// First, build …`, `// Merge into a single array …`, `// Use the first category's dates as the skeleton`       | Extract; if the ordering matters, a test named after the invariant.   |
| Restated signature  | `/** Strategy 2: Cross-rate (VND → SGD via USD) @example VND -> USD -> SGD */` above `if (strategy === "cross")` | Delete. The discriminant and the function call are the documentation. |
| History             | `// Mirrors the previous syncedDateRangeAtom write behavior`                                                     | Delete. `git log` is the archive.                                     |
| Confession          | `// hack`, `// for now`, `// this is ugly but works`, `// slightly wrong but fine`                               | Fix the cause, or open an issue and link it.                          |
| Archive             | `// import { electricSync } from "@electric-sql/pglite-sync";`, `// vector,`                                     | Delete the line. Recover from git.                                    |
| Decoration          | Banner rules, emoji, author/`Generated by` markers                                                               | Delete.                                                               |
| Lazy suppression    | `// @ts-expect-error: [todo] fix role type`                                                                      | Type the seam correctly. A TODO inside a suppression is not a fix.    |

### Strategy JSDoc duplicating the discriminant

```ts
// Before
/**
 * Strategy 2: Cross-rate (VND → SGD via USD)
 * @example VND -> USD -> SGD || SGD -> USD -> VND
 */
if (strategy === "cross") { … }

// After
if (strategy === "cross") { … }
```

If the strategies are genuinely non-obvious, the fix is a named union type plus one test per strategy — not prose above each branch.

### Suppression with a TODO

```ts
// Before
const canDelete = authClient.workspace.checkRolePermission({
	// @ts-expect-error: [todo] fix role type
	role: member.role,
	…
});

// After — one typed seam, no suppression
const canDelete = authClient.workspace.checkRolePermission({
	role: toWorkspaceRole(member.role),
	…
});
```

`toWorkspaceRole` narrows the synced `MemberSchema` role to the union the auth client accepts. If the mismatch is real, the fix is in `@hoalu/auth`'s exported role type, so every caller stops needing a cast.

## KEEPs in this repo, and why

- `apps/app/src/components/forms/tiptap.tsx:31–34` — Tiptap's `useEditor` returns a destroyed instance under React StrictMode, so `getHTML()` throws. External dependency behavior, unreachable from our code, verified against Tiptap's issue tracker. Format it as the exception, not as a greeting: state the dependency, the failure, and the guard.
- `apps/app/src/components/orb-motion.tsx` — one-word token labels (`// emerald`) beside bare rgba triples. The literal cannot read as the token.
- `apps/app/src/components/forms/select-recurring-bill.tsx:37–43` — prop contract for a shared form field: what the value filters and what happens when omitted. Keep it about the contract; never restate the type.

## Finding them

```sh
# comments added by the current branch
git diff main...HEAD -U0 | grep -E '^\+.*(//|/\*|\*)'

# confessions
rg -n '\b(hack|for now|temporary|todo|fixme|workaround|ugly|should be fine)\b' --type ts --type tsx apps packages

# corpses
rg -n '^\s*//\s*(import|const|let|return|if|await|[a-z]+:)' --type ts --type tsx apps packages

# suppressions
rg -n '@ts-(expect-)?error|oxlint-disable' --type ts --type tsx apps packages
```
