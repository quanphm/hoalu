## Rules (violating these = bug)

1. **Never mutate model nodes directly.** All changes via `model.doAction(Actions.*)`. GUI edits also flow through actions; intercept via `onAction` prop.
2. **Only symbols exported from `src/index.ts` are public API.** Everything else is internal.
3. **`factory: (node: TabNode) => ReactNode`** dispatched on `node.getComponent()`. Always handle unknown components. Per-window effects via `node.getDocument()` / `node.getWindow()` — see `demo/monaco.tsx` document-change remount pattern.
4. **Popout windows render into a different document.** Never use global `window`/`document` inside tab content; use `ref.ownerDocument` or `node.getDocument()`. See `docs/popout-windows.md`.
5. **`<Layout>` fills its parent**, which must be `position: absolute` or `relative` with explicit size.
6. Vendor JSON interfaces in `src/model/IJsonModel.ts` are generated by `scripts/generate-json-interfaces.ts` — never hand-edit in vendor.

## Mental model

- Model tree = JSON via `Model.fromJson(json)` / `model.toJson()`. Model is single source of truth, UI is derived.
- JSON node types: `row` (children: rows + tabsets; orientation alternates per nesting level), `tabset` (children: tabs/tabgroups), `tab` (hosts component), `tabgroup` (Chrome-style colored pill, direct child of tabset/border), `border` (only under top-level `borders`: `top`/`bottom`/`left`/`right`), `subLayouts` (named `IJsonSubLayout{layout, rect, type}` referenced by tab `subLayoutId`).
- Attribute inheritance: node attrs default from `global.*` prefixed by type — `tabXxx`, `tabSetXxx`, `borderXxx` (e.g. `global.tabEnableClose` vs per-tab `enableClose`). See `src/model/Attributes.ts`.
- Tabsets are created/destroyed dynamically as tabs move unless `enableDeleteWhenEmpty: false`.

## Basic setup

```typescript
import { Layout, Model, TabNode, type IJsonModel } from "flexlayout-react";
import "flexlayout-react/style/dark.css"; // or alpha_light, alpha_dark, alpha_rounded, light, underline, gray, rounded, aria, combined

const json: IJsonModel = {
  global: { tabEnableClose: true },
  borders: [],
  layout: {
    type: "row",
    weight: 100,
    children: [
      { type: "tabset", weight: 50, children: [{ type: "tab", name: "Explorer", component: "explorer" }] },
      { type: "tabset", weight: 50, children: [{ type: "tab", name: "Editor", component: "editor" }] },
    ],
  },
};

function App() {
  const modelRef = React.useRef<Model>(Model.fromJson(json)); // stable ref, never recreate per render
  const factory = (node: TabNode) => {
    switch (node.getComponent()) {
      case "explorer": return <ExplorerPanel />;
      case "editor": return <EditorPanel node={node} />;
      default: return <div>Unknown: {node.getComponent()}</div>;
    }
  };
  return (
    <div style={{ position: "relative", width: "100vw", height: "100vh" }}>
      <Layout model={modelRef.current} factory={factory} onModelChange={(m) => localStorage.setItem("layout", JSON.stringify(m.toJson()))} />
    </div>
  );
}
```

Pass tab data via `config` (`node.getConfig()`), persist it via the `save` node event. See "Node events" below.

## Actions (all mutations go through these)

Full signatures: `repos/flexlayout/src/model/Actions.ts`. Apply with `model.doAction(...)`:

- `Actions.addTab(jsonTab, toNodeId, location: DockLocation, index, select?)` — `index -1` = append. Deprecated alias `addNode` (same signature).
- `Actions.moveNode(fromId, toId, location, index, select?)`, `Actions.deleteTab(id)`, `Actions.deleteTabset(id)`, `Actions.renameTab(id, text)`, `Actions.selectTab(id)`, `Actions.setActiveTabset(id | undefined, layoutId?)`
- `Actions.setTabPinned(id, pinned)`, `Actions.setBorderType(id, "split" | "overlay")`, `Actions.maximizeToggle(tabsetId, layoutId?)`, `Actions.adjustWeights(nodeId, weights[])`, `Actions.adjustBorderSplit(nodeId, size)`
- `Actions.updateModelAttributes(attrs)`, `Actions.updateNodeAttributes(nodeId, attrs)`, `Actions.updateSubLayoutAttributes(layoutId, attrs)`
- Groups: `Actions.addTabToNewGroup(tabId, name?, color?)`, `Actions.ungroup(groupId)`, `Actions.removeTabFromGroup(tabId)`
- Popout/float (`type: "window" | "float"`): `Actions.popoutTab(id, type?)`, `Actions.popoutTabset(id, type?)`, `Actions.createSubLayout(layout, rect, type)` (alias `createPopout`), `Actions.moveFloat(layoutId, rect)`, `Actions.popoutFloat(layoutId, rect?)`, `Actions.dockFloatToLayout(layoutId, toId, location, index)`, `Actions.closePopout(layoutId)`, `Actions.movePopoutToFront(layoutId)`
- `Actions.group(action[])` — batch into one undo step / one `onBefore/AfterAction`.

```typescript
import { Actions, DockLocation } from "flexlayout-react";
model.doAction(Actions.addTab({ type: "tab", component: "editor", name: "New" }, tabsetId, DockLocation.CENTER, -1, true));
```

  onAuxMouseClick={(node, e) => {}}

## Popouts (summary of `docs/popout-windows.md`)

- Requires same-origin `popout.html` host; styles copied at runtime.
- In tab content use `node.getDocument()/getWindow()` or `ref.ownerDocument`, never globals. Remount document-bound libs (monaco, ag-Grid, charts) on document change — copy `demo/monaco.tsx`.
- CSS-in-JS needs `renderPopoutContent` (e.g. styled-components `StyleSheetManager target=popoutDocument.head`) + `onPopoutOpen/onPopoutClose`; see `demo/PopoutStyleProvider.tsx`.
- Secure env: same-origin, CSP `style-src` (copied inline styles break under nonce/hash — prefer CSS files), matching COOP/COEP, `supportsPopout={false}` to disable. Blocked `window.open` degrades to float panel.

## Node events + persistence

```typescript
function Editor({ node }: { node: TabNode }) {
  React.useEffect(() => {
    const id = node.setEventListener("save", () => { node.getConfig().draft = draft; });
    return () => node.removeEventListener(id);
  }, [draft]);
  React.useEffect(() => {
    const id = node.setEventListener("close", () => {/* confirm/teardown */});
    return () => node.removeEventListener(id);
  }, []);
}
```

Events: `resize {rect}` (imperative, no re-render — subscribe for canvas/charts), `visibility {visible}`, `close`, `save` (mutate `getConfig()` before `toJson()`).

Persistence: `onModelChange={(m) => localStorage.setItem(k, JSON.stringify(m.toJson()))}`; restore `Model.fromJson(JSON.parse(saved))`. Undo-safe replacement: `Model.fromJson(json, existingModel)` keeps mounted content — this is what `useUndo` does internally.

## Accessibility + testing

- Accessibility (`docs/accessibility.md`): ARIA `tablist/tab/tabpanel`, splitter `separator`, `menu/menuitem`; arrows navigate, Enter/Space select, `Ctrl+Delete` close, `F2` rename, `Escape` closes overlay; `keyMap` merges over `defaultKeyMap`; focus color `--fl-color-focus` / `--flexlayout-color-focus`.
- Testing (`docs/testing-your-layout.md`): every element has `data-layout-path` — `/r<n>/ts<n>`, `/border/<left|right|top|bottom>`, `…/tb<n>` (button) vs `…/t<n>` (panel), `…/g<n>` group pill, `…/tabstrip`, `…/s<n>` splitter, `…/button/<max|overflow|close|popout|float|pin>`, `/popup-menu`. Indices shift after moves — assert stable states. Fixtures: `demo/public/layouts/*.layout`; helpers: `tests-playwright/helpers.ts`.

## Best practices / pitfalls

- Own the model correctly: stable `useRef(Model.fromJson(json))` for static layouts, or `useUndo(...)` ownership for undoable ones. Never `Model.fromJson()` inline during render.
- Persist in `onModelChange`, not per-button handlers.
- Memoize `factory`; always include `default` unknown-component branch.
- Keep tab data in `config` + `save` listener, not in React state alone.
- Provide reset: `setModel(Model.fromJson(defaultJson))` (or `window.location.reload()` only for throwaway demos).
- Empty tabsets vanish unless `tabSetEnableDeleteWhenEmpty: false` + `onTabSetPlaceHolder`.
- Border tabs: `location`, `size`, `enableAutoHide`, `autoSelectTabWhenOpen/Closed`.
- For large layouts lazy-load factory components (`React.lazy`).
